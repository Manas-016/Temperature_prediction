# 🌦️ London Temperature Prediction

A machine learning project that predicts the **mean temperature in London** using historical weather data. The project covers the complete machine learning workflow, including data preprocessing, exploratory data analysis, feature engineering, model training, evaluation, and experiment tracking using MLflow.

## 📌 Project Overview

The goal of this project is to predict London's mean temperature based on historical weather conditions.

The dataset was downloaded from **Kaggle** and contains historical weather observations for London.

This project was built to gain practical experience with the complete machine learning workflow and to compare different regression algorithms.

## 📊 Dataset

The weather dataset was obtained from Kaggle.

The dataset contains weather-related features such as:

* Cloud cover
* Sunshine
* Global radiation
* Maximum temperature
* Mean temperature
* Minimum temperature
* Precipitation
* Pressure
* Snow depth

## 🔍 Exploratory Data Analysis

The project includes exploratory analysis to understand the weather data and identify relationships between different variables.

### Temperature Trend

The monthly mean temperature was analyzed to understand how temperature changes over the years.

### Correlation Analysis

A correlation heatmap was used to analyze relationships between the numerical weather features.

## 🤖 Machine Learning Models

Three regression algorithms were trained and compared:

### 1. Linear Regression

Used as a baseline regression model to understand the relationship between the selected weather features and mean temperature.

### 2. Decision Tree Regressor

Decision Tree models were trained with different values of `max_depth`:

* `1`
* `2`
* `10`

### 3. Random Forest Regressor

Random Forest models were also trained with different values of `max_depth`:

* `1`
* `2`
* `10`

## ⚙️ Data Preprocessing

The following preprocessing techniques were used:

### Missing Values

Missing feature values were handled using `SimpleImputer` with the mean strategy.

### Feature Scaling

Features were standardized using `StandardScaler`.

### Train-Test Split

The dataset was divided into:

* **80% training data**
* **20% testing data**

## 📏 Model Evaluation

The models were evaluated using **Mean Squared Error (MSE)**.

A lower MSE indicates better prediction performance.

The project prints the MSE for each trained model and also displays the predictions generated by each model.

## 📈 Experiment Tracking with MLflow

**MLflow** was used to track the machine learning experiments.

The project logs:

* Model parameters
* Mean Squared Error
* Trained machine learning models
* Different experiment runs

This makes it easier to compare different models and configurations.

> The `mlruns/` directory is generated locally by MLflow and is excluded from the Git repository using `.gitignore`.
